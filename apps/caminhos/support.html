Caminhos Support

Getting started with calm route guidance.

A practical guide to setup, route preferences, and troubleshooting for a smoother navigation experience.

Setup

  1. Install Caminhos and grant location permission.
  2. Select voice style, pace, and guidance density.
  3. Save favorite destinations for faster route planning.
  4. Start a route and use preview mode before departure.

Key features

  • Route previews with timing and transition context.
  • Step-by-step guidance with optional repeats.
  • Favorites for home, work, and frequent places.
  • Low-verbosity mode for confident repeat travel.

Troubleshooting

  • If the route does not refresh, verify data connectivity.
  • If speech feels too dense, reduce prompt frequency in settings.
  • If GPS drift affects guidance, stop briefly and request an update.
  • If arrival prompts seem early, confirm walking pace settings.
