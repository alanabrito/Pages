blint Support

Setup, features, and troubleshooting.

Everything needed to get started with blint, tune the experience, and resolve the most common issues.

Setup

  1. Install blint and allow location access while using the app.
  2. Enable spoken feedback and optional haptics in onboarding.
  3. Choose concise or detailed cue style.
  4. Start a quick orientation session from the home screen.

Key features

  • One-tap orientation mode.
  • Nearby context summaries.
  • Directional feedback tuned for speed.
  • Repeat-last-cue action for quick confirmation.

Troubleshooting

  • If cues are delayed, verify network and location permissions.
  • If audio is too verbose, switch to concise mode in settings.
  • If haptics are missing, confirm haptics are enabled on the device.
  • If location feels inaccurate, recalibrate by pausing and restarting a session.
