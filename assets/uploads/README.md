Upload your gallery images into these folders:

- `assets/uploads/passions/`
- `assets/uploads/homes/brazil/`
- `assets/uploads/homes/france/`
- `assets/uploads/homes/us/`

Then update the `gallery-data` JSON inside the corresponding HTML page so the gallery points to the new files.

For videos:

- Use a YouTube embed URL such as `https://www.youtube.com/embed/VIDEO_ID`
- Use an Instagram embed URL such as `https://www.instagram.com/p/POST_ID/embed`
